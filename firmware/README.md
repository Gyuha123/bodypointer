# HeadMouse-IMU 펌웨어 — BodyPointer 연동판 v2.0

BodyPointer를 실행하면 블루투스로 바로 연결되고, **연결되는 즉시 커서를 움직일 수 있게** 만든 펌웨어입니다.
원본(`Downloads\head_mouse`)은 그대로 두었습니다. 배선, 통신 형식, 블루투스 이름(`HeadMouse-IMU`)은 같습니다.

## 바뀐 점

| | 원본 | 연동판 v2.0 |
|---|---|---|
| 켤 때 | 매번 2초 자이로 보정 (가만히 있어야 함) | **저장된 보정값으로 바로 동작** (처음 한 번만 보정) |
| 블루투스가 연결될 때 | 강제로 다시 보정 → 머리에 쓴 채로는 한참 안 움직임 | **다시 보정하지 않음 → 연결 즉시 사용** |
| 보정값 | 껐다 켜면 사라짐 | ESP32 내부 저장소(NVS)에 저장 |
| 흐름(드리프트) 방지 | 수동 재보정만 | 머리가 2초 동안 아주 고요하면 **자동으로 조금씩 미세 보정** |
| PC가 장치를 알아보는 방법 | 데이터가 올 때까지 기다림 | 연결 즉시 **식별 패킷(type 4, 버전)** 전송, `i` 명령으로도 요청 가능 |

보정 스위치와 `c` 명령은 그대로 언제든 다시 보정합니다(2초 가만히). 전원 절약 설정(묶음 전송, 송신 출력, LED 밝기)과 저전압 진단도 그대로입니다.

## 굽는 방법 (둘 중 하나)

### A. Arduino IDE
1. `esp32_head_imu\esp32_head_imu.ino` 열기
2. 보드 **ESP32 Dev Module**, 포트 선택(USB) → 업로드
   (외부 라이브러리 필요 없음. `Preferences`는 ESP32 보드 패키지에 들어 있음)

### B. 이미 빌드된 파일 (`firmware_bin\`)
ESP32 보드 패키지 3.3.8로 빌드했습니다. `esptool`이 있으면:
```
esptool --chip esp32 --port COM3 --baud 921600 write_flash 0x0 firmware_bin\esp32_head_imu.ino.merged.bin
```
(`COM3`은 USB로 연결된 ESP32 포트로 바꾸세요. merged.bin = 부트로더+파티션+프로그램 전체)

## BodyPointer에서 쓰기
1. Windows 블루투스 설정에서 **HeadMouse-IMU**가 페어링돼 있으면 끝 (이미 되어 있음)
2. BodyPointer 실행 → 설정 → 머리 센서: 상태에 **“연결됨 (블루투스, 연동판 펌웨어 2.0)”**
3. 처음 한 번 **‘방향 맞추기’**
4. 펌웨어를 새로 구운 직후 첫 연결 때는 보정값이 없으니 **2초만 가만히** 있으세요 (이후로는 바로 동작)

BodyPointer는 Windows에 저장된 블루투스 장치 이름으로 **HeadMouse-IMU 포트만** 찾아 엽니다.
같은 PC에 페어링된 이어폰·휴대폰 등 다른 블루투스 기기에는 연결을 시도하지 않습니다.

## 시험 상태
- 컴파일: 성공 (프로그램 82%, 메모리 13%)
- 실제 보드에 굽거나 블루투스로 연결해 보는 시험은 하지 않았습니다.
