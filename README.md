# BodyPointer — 전신 포인터 (v0.6)

웹캠 하나로 **원하는 신체 부위(코, 턱, 손가락, 어깨, 팔꿈치, 무릎, 발 등)** 를 마우스로 바꿔 Windows PC를 조작합니다.
영상은 이 PC 메모리에서만 처리하고 저장·전송하지 않습니다. 참고용 보조 도구이며 의료기기가 아닙니다.

## 실행
`BodyPointer 실행.bat` 더블클릭 (또는 `main.py` 더블클릭).

처음 설치할 때만:
```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python setup_models.py
```

## 주요 기능
| 기능 | 설명 |
|---|---|
| 머무르기 클릭 | 원하는 곳에 잠시 머무르면 클릭 메뉴(클릭·더블·우클릭·드래그·스크롤) |
| 떨림 대응 | 떨림 보정 0~200(100 이상은 ‘고무줄’ 방식으로 부드럽게), **떨림 클릭 보조**(잠깐 튀어도 게이지 유지 + 게이지가 차면 커서 붙잡기), 움직임 → ‘떨림이 심해요’ 한 번에 맞추기 |
| 감도 | 절대 모드 감도 최대 8배, 상대 모드 속도 최대 12배 — 카메라와 멀거나 조금만 움직일 수 있어도 화면 끝까지 |
| 키보드 바 | 툴바 ‘키보드’ 또는 `Ctrl+Alt+K`. 두벌식 한글·영문·숫자, 복사·붙여넣기 등 편집 키. 키 머무는 시간 기본 1.2초 (설정 → 클릭에서 0.6~3초 조절) |
| 자동완성 | 초성만 쳐도 찾기(ㅇㄴㅎ → 안녕하세요), 앞부분 일치, 다음 단어 예측. 쓸수록 내 단어가 앞으로 |
| 사용 기록 | 툴바 ‘저장’을 누르면 그동안의 사용 통계를 저장 (종료할 때도 물어봄) |
| 대시보드 | 하루 사용 시간, 움직이는 범위 추이, 클릭 정확도, 클릭 위치, 자주 쓴 기능·단어, CSV 내보내기 |
| 맞춤 추천 | 자주 쓰는 기능 → 표정 제스처 등록, 이어 쓰는 동작 → 묶음 버튼, 머무는 시간·떨림 보정 조정 등 |
| 빠른 실행 | 가장 자주 쓴 기능 3개가 툴바에 자동으로 올라옴 |
| 툴바 접기 | 툴바 맨 위 ‘접기’를 누르면 재개/정지만 남김 (‘열기’로 다시 펼침) |
| 표정 제스처 | 눈썹 올리기·입 벌리기·웃기·눈 감기·입술 내밀기에 원하는 기능 연결 |
| 표정 유지 동작 | 표정을 짓는 동안 **꾹 누르기(드래그)**, **휠 누른 듯한 스크롤**. 표정을 풀면 끝 |
| 추천 세트 | 눈썹=클릭, 입 벌리기=꾹 누르기, 웃기=스크롤, 눈 감기=키보드를 한 번에 적용 |
| 머리 센서 리모컨 | 이마에 붙이는 ESP32 자이로 센서(‘HeadMouse-IMU’). **어둡거나·얼굴이 가려지거나·카메라가 꺼지면 자동으로 머리 센서로 전환**, 밝아지면 카메라로 복귀. 누워서 쓸 땐 ‘항상 머리 센서’. 고개 끄덕 = 클릭(선택). 설정 → 머리 센서에서 ‘방향 맞추기’ 한 번. 최신 펌웨어(IMU 8개씩 묶음 전송)는 장치 시각 기준 재생 버퍼로 부드럽게 풀어 쓰고, 배터리 부족으로 센서가 재부팅되면(저전압 리셋) 경고 |
| 머리 센서 자동 연결 | 실행하면 Windows에 저장된 블루투스 이름으로 **HeadMouse-IMU 포트만** 찾아 바로 연결 (이어폰·휴대폰 등 다른 기기는 건너뜀). 연동판 펌웨어 v2.0을 쓰면 보정값이 저장돼 연결 즉시 사용 |
| 중복 클릭 방지 | 머무르기·표정·고개 끄덕 클릭이 0.6초 안에 겹치면 한 번만 누름 (Windows가 더블클릭으로 오인하지 않게) |
| 링크 열기 제스처 | 제스처 목록 맨 아래 ‘＋ 새 링크 추가…’ → 사이트를 고르거나 주소 입력 → 그 표정을 하면 기본 브라우저로 열림 (http/https 주소만 허용) |
| 내 표정으로 맞추기 | 1.5초 편히 → 3초 표정 짓기로 그 사람에게 맞는 인식 기준을 자동 설정 |
| 쉬어 가기 | 40분 휴식 알림, 움직임이 크게 줄면 휴식·부위 교대 제안 |

## 단축키
| 키 | 동작 |
|---|---|
| `Pause`, `Ctrl+Alt+P` | 클릭 멈추기 / 다시 시작 |
| `Ctrl+Alt+K` | 키보드 열기 / 닫기 |
| `Ctrl+Alt+N` | 다음 즐겨찾기 부위 |
| `Ctrl+Alt+M` | 카메라 커서 끄기 / 켜기 |
| `Ctrl+Alt+C` | 커서 고정 (상대 모드) |
| `Ctrl+Alt+S` | 설정 창 열기 |
| `Ctrl+Alt+Q` | 프로그램 종료 (툴바·웹 엔진까지 모두) |
| `Ctrl+Alt+R` | 머리 센서 ‘항상’ ↔ ‘자동’ 전환 (불 끄기 전에 누르면 편함) |

## 하체 인식 안정화
- 다리 부위는 더 정확한 포즈 모델(`pose_landmarker_full`)을 자동으로 사용
- 발·발목·엉덩이는 여러 점(발끝·뒤꿈치·발목 등)의 신뢰도 가중 평균을 기준점으로 사용
- 신뢰도가 낮은 프레임은 버리고 0.4초 동안 직전 위치 유지, 갑자기 튀는 오검출 무시, 신뢰도 비례 평활화
- 다리가 화면에 잘 안 보이면 카메라 배치를 안내

## 구조
```
bodypointer/
  web/            인식 엔진 (Qt WebEngine에서 실행하는 MediaPipe WASM)
  vision.py       카메라·인식 연결, 부위 기준점 계산
  stabilize.py    좌표 안정화 (하체용)
  engine.py       커서·머무르기·클릭 상태 기계
  hangul.py       두벌식 한글 조합기
  predict.py      자동완성 (초성·앞부분·다음 단어)
  actions.py      실행 가능한 동작 목록 (키보드·툴바·제스처 공용)
  gestures.py     표정 제스처 감지
  usage.py        사용 기록 수집·저장 (SQLite)
  insights.py     기록 분석 → 맞춤 추천
  ui/             디자인 시스템, 메인 창(사이드바 8페이지), 툴바, 키보드 바, 차트, 마법사
tests/            단위 테스트 27개 (python -m unittest discover tests)
```

## 저장하는 데이터 (`%APPDATA%\BodyPointer`)
설정값, 가동 범위 숫자, 세션별 통계(사용 시간·클릭 수·떨림·움직임 범위·기능별 사용 횟수), 키보드로 쓴 **단어의 빈도**.
영상·사진·원본 랜드마크·입력한 문장은 저장하지 않습니다. 설정 → ‘모든 기록 삭제’로 한 번에 지울 수 있습니다.
